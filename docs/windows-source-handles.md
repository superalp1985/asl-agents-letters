# Windows 源文件能力

T08 句柄能力已实现，21 项测试函数通过；符号链接和 8.3 实际别名夹具受
本机环境限制尚未执行，T08 不标为整体验收。

## 接口与职责

`SourceGrant::open(root, protected_root, rules)` 只能由本机可信 broker 在
人类授权后调用。`root` 是已有的共享目录，`protected_root` 是已有的应用数据根。
`SourceRules` 接受明确扩展名白名单及单文件字节上限，上限不超过 64 GiB。
它不是线上消息字段，不能从 peer、模型输出或资源文档直接构造。

`open_authorized_source(&grant, relative)` 返回只实现读取的 `AuthorizedFile`。
该能力只公开文件身份与长度，不公开路径、原始句柄或可重新打开的文件对象。
纯策略 `Permit` 和目录句柄能力必须同时满足，不能互相替代。
后续 importer 负责先获得磁盘额度、重验授权、建立不可变快照，再允许发布。

## 句柄边界

实现复用固定版本 `windows 0.62.2` 的 NT/Win32 API。
从本地固定 NTFS 卷根开始，逐级使用 `NtCreateFile` 的
`OBJECT_ATTRIBUTES.RootDirectory` 打开一个组件。所有组件使用
`OBJ_DONT_REPARSE` 与 `FILE_OPEN_REPARSE_POINT`；不通过检查后重新按路径打开。

输入拒绝绝对/UNC/device/verbatim 路径、`.`、`..`、重复分隔符、ADS、
设备保留名、控制符、通配符及尾随空格/句点。
打开后检查真实类型、reparse tag、文件身份、卷身份、删除状态和硬链接数量。
源文件只允许普通磁盘文件，硬链接数量必须为 1。
每一级实际规范长名必须与请求的组件精确匹配，短名和大小写别名拒绝。
驱动器字母大小写不影响使用；通过 `QueryDosDeviceW` 拒绝 SUBST 别名，
包括指向整个卷根的别名，而不只检查最终路径是否从某个目录开始。

`GetFinalPathNameByHandleW` 用于句柄已打开后的长名和目录关系核验，
不作为主要访问边界，也不把它的结果交给普通路径打开。
共享模式只允许读，拒绝其他写入与删除共享；从卷根到文件的祖先句柄
在读取期间一直持有。`SourceGrant` 被释放后，`AuthorizedFile` 仍持有这些句柄。
每次读取前重新检查文件身份、长度、硬链接数和普通文件属性。

应用数据根也逐级固定并在能力存续期间保留句柄。共享根与数据根相同、
位于数据根之内或覆盖数据根时，整项授权拒绝。
这是保守的目录授权规则：应选择数据根之外的明确资料目录。
将来对经验或头像的发布使用单独资源引用，不能通过普通目录授权公开数据根。

## 恢复与限制

`FileIdentity` 包含卷序列号及 128 位文件 ID。
`SourceGrant::restore` 重新走完整的句柄遍历并核对保存的根身份，
目录在相同路径被替换后不会自动继承旧授权。
持久化这些身份、撤销时关闭活动能力和逐次读取前的策略栅栏，
由后续 core/store 集成实现。

源目录长期持有期间可能阻止编辑器替换目录；源文件只在实际读取期间锁定。
被占用或不满足规则时拒绝读取，不降低共享或链接检查来继续。
本模块不负责应用数据根创建/ACL、写目录能力、下载清理、
AppContainer、Job Object、SQLite 撤销、lease 或网络发送。
不能把本模块视为抵抗管理员、内核入侵或同账号恶意程序的独立沙箱。

## 验证

测试仅使用 E 盘一次性夹具。真实 junction、硬链接、ADS、SUBST 及
重命名锁定和替换对照已执行；并发重命名在能力存活期间被锁拒绝。
测试期间成功新增一个硬链接，之后能力读取立即失败且未输出字节。
SUBST 对目录和整个 `E:\` 的映射均真实建立并被拒绝，测试结束后移除。
竞态夹具记录 256 次被锁拒绝的重命名，不能声称成功交错替换了 256 次。
符号链接创建返回 Windows 错误 1314，目录和文件 symlink 夹具均未执行。
本机没有给测试文件/目录分配 8.3 别名，实际别名分支未执行。
未修改开发者模式、系统权限或卷设置来绕过这些限制。
普通路径成功或静态阅读不能替代缺失的真实系统测试。

独立只读工程复核未确认越界或 unsafe 正确性缺陷，发现卷根 SUBST 规则
遗漏和未写入规范的扩展名长度限制；实现已补显式驱动映射检查并移除额外
长度限制。复核另提出竞态夹具应容忍预期共享冲突，已加入保持替换状态的有界重试。
补充用例覆盖长扩展名、两个根的祖先大小写变体、整个卷的 SUBST 和
能力存活期间的硬链接变化。复核者独立重跑
`cargo test -p asl-policy --test path_boundaries --locked -- --nocapture --test-threads=1`，
21 项测试函数通过，并确认上述三个不可用夹具分支和 0 次成功并发替换。
随后工作区测试共 165 项通过，Clippy（`-D warnings`）、格式检查通过。
本轮没有改变协议、依赖版本或锁文件；许可证和 CDDL 未重复执行。
