# 本机资源滥用防护

## 目标

允许一个控制者创建多个 Agent，也允许一个 Agent 在多台设备运行。ASL 不尝试证明现实世界“一人一个身份”。区块链只能证明某个密钥控制了某条登记状态，不能证明人、设备安全或 Agent 诚实。

目标是远端身份数量不能绕过本机统一上限，不能借协议解析、DHT、链证明、文件写入或模型调用耗尽个人电脑，也不能诱导本机越权。

## 分身和女巫威胁

| 威胁 | 可检测性 | 防护 |
| --- | --- | --- |
| 合法运行多个 Agent | 可见，但不应处罚 | 同一 ASL supervisor 下共享机器级总预算 |
| 同一 Agent 多设备 | 由设备证书识别 | 先按 AgentId 合并，再按设备分桶 |
| 同一密钥克隆并发 | 只能部分发现 | 重复序号、同证书异地并发、MLS 状态冲突告警并降配；被动克隆不可可靠发现 |
| 多个独立链身份 | 无法证明是否同一操作者 | 新/未验证类配额、网络来源桶和全局总上限 |
| DHT Sybil / eclipse | 无法彻底消除 | 多个独立 bootstrap、并行不相交查询路径、来源多样化、签名记录；接受漏答与审查仍可能 |
| 恶意已验证节点 | 可归因到密钥，不等于可信 | 与未验证身份同样受全局限额和本地授权约束；验证身份不免除限额 |

不得把付费、购买积分、实名、生物信息或高端硬件设为个人电脑安全前提。注册成本、信任和贡献均不是本地授权凭证。

## 分层额度

以下为实现起始上限，T37 必须通过压力与攻击测试后才能冻结；任一子桶受父桶约束，不允许通过多身份相加突破全局值。

| 层 | 起始限制 |
| --- | --- |
| 单台机器/用户会话 | 单一 supervisor；最多 64 条已建立连接、16 条待认证入站连接、128 个全局排队请求 |
| 入站帧 | 长度前缀检查后才分配；控制帧 64 KiB；CBOR 深度 16、容器项 4,096；认证前不解压 |
| 未验证来源 | 每连接最多 3 次握手/分钟；每秒最多 2 次昂贵签名或链证明校验；不调用 Agent 模型 |
| IPv4 /24、IPv6 /56 | 最多 8 条待认证连接、32 条已建立连接；relay 流额外计入 relay 总桶 |
| AgentId | 最多 8 个并发应用请求、4 个传输块 |
| 设备 PeerId | 最多 4 个并发应用请求、2 个传输块 |
| 模型 | 全局最多 4 个任务并发；陌生/未锚定来源默认不调用；每个策略周期设统一请求/输入/输出上限 |
| 磁盘 | 所有入站任务先 reserve；未知来源总 reserve 起始 512 MiB；单对象硬上限仍遵循传输规范 |

最终数值写入一个版本化本地资源策略，所有 Agent 身份共用同一个 supervisor 预算。单个 Agent 可设更低上限，任何配置都不能把全局上限提高到编译/系统策略上限之上。`Job Object`/AppContainer 限制进程 CPU、内存、子进程与网络能力；应用层桶负责连接、请求、模型和磁盘类别额度，两者不可互相替代。

## 授权和不可信数据

- 远端结构化消息、文件载荷、链状态、DHT 数据都作为不可信输入。它们不能提供路径、命令、模型 URL、权限、额度或联系人变更。
- 检索必须在本地 grant/audience 过滤后执行。模型只在本机授权允许时看到最小片段；远端内容是数据，不是指令。远端文件默认隔离，不自动交给模型。
- 硬上限、磁盘预留、取消、撤权和错误处理均由确定性 core 执行。模型、贡献分和信任分都不能修改这些状态。
- 失败关闭只收紧访问；链、DHT 或 RPC 不可用时切到最低资源类别，不把“身份已验证”推导成“文件已授权”。

## 验收

压力测试至少使用 1,000 个模拟 AgentId 和多设备 PeerId，同时覆盖畸形/超深 CBOR、慢速握手、重复链证明、DHT flooding、断续块、磁盘预留争抢和模型排队。测量峰值 CPU、RSS、队列、连接数、写盘字节与模型调用；所有指标不得超过 supervisor/OS 硬上限，联系人保留的资源份额不得被未知来源挤占。该测试不证明现实网络中不存在女巫，只验证女巫不能突破本机预算。
