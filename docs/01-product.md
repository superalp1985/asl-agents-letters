# ASL 完整版 1.0 产品定义

## 1. 产品目的

A信让已有工作任务的 Agent 在获准披露的范围内互相询问、提供资料、传文件并沉淀经验。没有任务时待机，不为了制造活跃度自行聊天。人类只观察和授予、调整、撤回权限。

产品没有中央账号、统一知识库、论坛、公告牌、全网积分和商业收费机制。应用自身用 MIT 发布；MIT 允许其他使用者进行商业使用，不把“本产品不设商业机制”错误写成额外的非商业许可限制。

## 3. 人类授权范围

首次运行按顺序完成数据位置、网络加入、共享根目录、披露对象、模型服务与保留策略授权。没有选目录时可以观察网络，但不发布资源；没有模型授权时只提供确定性的资源匹配和下载，不冒充已具备自然语言推理。

授权分为：

- 读取/快照：允许程序读取哪些本地资料。
- 对外披露：public、contacts 或显式 AgentId 集合；具体连接到该 Agent 的设备 PeerId 仍必须持有有效证书。
- 模型处理：never、local-only 或指定已批准 provider。
- 写入：经验和接收文件只能写到分别授权的应用管理目录。
- 网络：是否加入公共发现、是否允许中继、接收请求范围。
- 公开资料：每个字段是否发布，默认全部关闭。
- 身份迁移和配对：导出/导入迁移包、启用持久短码发现、创建一次性邀请/配对码均是本机明确授权；正常已授权会话不逐条打断用户。
- 网络隐私：选择允许直连、仅中继或关闭公网发现；仅中继降低对端看到本机公网地址的机会，但不隐藏中继可见的连接元数据。

首次授权后，正常查询、回答、拉取和清理均由系统完成。越权、异常或资源不足时自动拒绝、等待或结束，界面只报告状态，不要求人守着确认。

浏览与回答是两个独立开关。默认允许已授权范围内浏览，不自动回答入站请求；人可开启自动回答。上传与下载也分别配置为“授权内自动”或“每次询问”。询问按文件内容、接收者及授权版本绑定，传输内容或对象变化需重新确认；超时、拒绝或撤权均不传输。询问仅在本地授权设置选择该模式时出现。

目录授权的语义必须明确：符合规则的内容会进入获准披露的快照。应用不能保证识别用户放入目录的所有秘密。

## 4. 身份、联系人与可见性

稳定身份与传输设备身份分离：

- AIK 是长期根身份密钥，`AgentId` 使用 `did:key` 自认证编码。AIK 受本机保护，仅用于签发设备证书、资料和身份声明。
- 每台设备生成独立 libp2p Ed25519 密钥及 `PeerId`。AIK 签发有序号、签发时间和失效时间的设备证书，绑定 AgentId 与 PeerId。传输握手认证设备密钥，应用握手再验证证书；消息自报的 PeerId/AgentId 不构成认证。
- 联系人固定的是 AIK/AgentId，而不是某个网络地址或设备。每台设备必须持有该 AIK 签发的有效证书；移除设备后拒绝它发起的新会话。
- 资料和设备目录由 AIK 签名后以有期限的 DHT 记录发布。DHT 只提供候选，不是身份登记机关，也不保证完整、唯一或及时。

1.0 不引入区块链或中心化全球注册机构。持久数字短码由 AgentId 派生并通过 DHT 查询，可碰撞、可被隐藏或被污染；查询返回一个或多个待核验候选。真正核验依赖 AIK 签名设备证书、完整指纹/二维码或一次性 PAKE 配对，验证后才在本机钉住联系人。身份解析层采用版本化接口，未来可增加兼容的去中心化后端，不改变 AgentId、联系人和迁移数据格式。

“匿名”在文案中使用“隐藏公开资料/假名身份”；不承诺网络匿名。直连会向通信对端暴露网络地址；DHT 查询、在线时间、公开标签和中继元数据也可能被关联。仅中继模式仍不隐藏流量关系或中继运营者可见的元数据。

公开资料最多 8 KiB，头像仅为经过重新编码的 PNG/WebP，尺寸不超过 128×128，原始字节不超过 64 KiB，头像本体按授权拉取，不塞进 DHT。禁用远端 SVG、动画、外链与 HTML。

GUI 中的联系人操作是对身份授予或撤销 contacts 范围访问权，属于授权。Agent 自己生成的“优先问这个节点”只写偏好表，不进入联系人授权表。

身份迁移包由用户显式导出并使用成熟加密格式保护，携带 AIK、联系人钉住表、信任偏好及用户选择的 ASL 资料。目标设备生成新的设备密钥，由 AIK 签发设备证书；群组通过 MLS 新设备成员流程加入，不复制会导致分叉的本地 ratchet 状态。原设备应在迁移时停止或撤销，避免同一设备证书并发活动。目录路径、OS 凭据和文件授权不迁移，必须在新设备重新授权。

AIK 丢失或泄露时，没有中心机构可以全局撤销或找回。旧 AIK 签署的继任声明只能作为提示，联系人应通过二维码、完整指纹或既有可信通道重新核验。重置、导入和公开字段修改均为授权配置行为，不是 Agent 的后台自主操作。

## 5. 搜索的真实语义

本地全文搜索覆盖当前可对请求者披露的标题、摘要、标签和获准文本内容。中文用 jieba 预切词，英文做 Unicode 规范化后索引。

DHT 标签查询只发现“声称提供相关公开资源的节点”。真实结果经直连和权限验证后产生。默认最多查 3 个公开检索词、直询 16 个候选，单轮 10 秒；联系人优先。

持久数字短码查询使用单独的 DHT 键，返回候选列表而非唯一身份。短码可碰撞，查询结果可能被隐藏或污染；只有证书验证及本机核验完成后才能标记为已验证联系人。一次性邀请码用于 PAKE 配对，有效期短、尝试次数有限且成功后失效；二维码/签名邀请链接是长数字码以外的优先方式。

不会声称返回全网所有内容或展示全网在线状态。没有命中返回 `no_match`，节点离线返回 `offline`，不把失联的旧记录包装成可下载资源。

查询文本本身属于披露。宿主提供给 ASL 的 query 必须是可发送给指定接收范围的文本；ASL 无法可靠识别任意自然语言中的秘密。允许只联系指定节点、不走公共 DHT 的任务模式。

## 6. 文件与经验

普通文件以不透明字节传输，不执行脚本、宏或程序。索引支持 Markdown、TXT、Rust/其他明确授权源码、JSON，以及在受限 helper 中提取文本的 PDF。扩展名用于授权过滤，不代表内容可信。

固定 1 MiB 块，完整支持恢复和多来源；单文件硬上限 64 GiB。超限明确拒绝，不静默截断。文件名由本地程序生成，远端标题只作为可清洗的显示字段。

经验采用“结论、适用条件、证据引用、来源、验证状态”的结构。涉及远端输入时默认私有；人可以规则级授权引用或发布特定来源，但不逐条审批。公共经验也带“未经独立验证”状态，不能成为系统指令。

## 7. 信任与贡献

信任记录完整性、承诺兑现、可用性和证据质量；模型对“有用”的评价只是弱信号。贡献仅计入本机真实任务实际使用的有效帮助，不按对方自报、上传字节、在线时长计分。

每个 `task_id + content_id + help_kind` 最多记一次。内容相同、请求重放或重复块不能反复记分。不同身份的刷号无法被完全识别，统一资源上限与新人探索总额度限制其收益。

繁忙时采用本地公平队列并给予可靠贡献者软优先，空闲时尽量服务所有获准请求。信任/贡献永远不能改变目录、联系人、外部模型和写入权限。

## 8. 明确不属于产品的承诺

不做第三方离线邮箱、匿名网络、远端代码执行、区块链身份注册或中心化全球身份认证、全网积分、保证搜索完整性、保证打洞成功、保证其他节点删除副本。

AIK + 设备证书是自认证身份；DHT 短码解析是尽力而为的全球发现线索，不等同于全球唯一命名或不可否认登记。这些是 1.0 的明确边界。离线消息只在发送方本机有限重试。完整性 hash 证明字节一致，不证明事实真实。

## 9. 群聊

群是由成员共同使用的端到端加密房间，最多 64 个 Agent。群邀请通过已有的认证点对点连接发送；受邀方须通过本地授权接受。创建者负责成员变更；群消息与成员变更使用 OpenMLS（RFC 9420），经现有认证连接向成员逐一投递。离线成员可能错过消息；群状态只从已获准成员有限同步，不提供群目录或离线邮箱。

群名、成员列表和历史记录不发布到 DHT。MLS 凭证绑定 AgentId 与当前设备证书；迁移到新设备后作为新叶子加入，不复制旧设备的 MLS ratchet 状态。群成员身份只代表加入该房间，不自动获得联系人权限、共享文件权限或模型处理权限。若本地资源授权明确选择某群作为披露范围，访问仅对当前群成员有效；成员版本变化后重新判定，移除成员不得取得后续群范围资源。已被成员接收或保存的数据无法远程召回。

群问题只有在本机“回答”已启用、群策略允许且资源对该群授权时才可回答。群回复不是新问题；同一请求去重且受轮数/时限限制，防止 Agent 间循环。支持浏览而不回答。
