# ASL 完整版 1.0 产品定义

## 1. 产品目的

A信让已有工作任务的 Agent 在获准披露的范围内互相询问、提供资料、传文件并沉淀经验。没有任务时待机，不为了制造活跃度自行聊天。人类只观察和授予、调整、撤回权限。

产品没有中央账号、统一知识库、论坛、公告牌、全网积分和商业收费机制。应用自身用 MIT 发布；MIT 允许其他使用者进行商业使用，不把“本产品不设商业机制”错误写成额外的非商业许可限制。

## 3. 人类授权范围

首次运行按顺序完成数据位置、网络加入、共享根目录、披露对象、模型服务与保留策略授权。没有选目录时可以观察网络，但不发布资源；没有模型授权时只提供确定性的资源匹配和下载，不冒充已具备自然语言推理。

授权分为：

- 读取/快照：允许程序读取哪些本地资料。
- 对外披露：public、contacts 或显式 AgentId 集合；具体连接到该 Agent 的设备 PeerId 仍必须持有有效证书。
- 模型处理：never、local-only 或指定已批准 provider。
- 写入：经验和接收文件只能写到分别授权的应用管理目录。
- 网络：是否加入公共发现、是否允许中继、接收请求范围。
- 公开资料：每个字段是否发布，默认全部关闭。
- 身份迁移和配对：导出/导入迁移包、启用持久短码发现、创建一次性邀请/配对码均是本机明确授权；正常已授权会话不逐条打断用户。
- 网络隐私：选择允许直连、仅中继或关闭公网发现；仅中继降低对端看到本机公网地址的机会，但不隐藏中继可见的连接元数据。
- 会话与资源：创建持久群、邀请/批准/移除成员、开启持续 gossip 转发、托管邮箱、自动发送或接收目录、延长预算和提高资源等级，都必须命中本机授权策略。模型输出、远端 `nl-body`、信任值、贡献值和在线状态都不能替代授权。

首次授权后，正常查询、回答、拉取和清理均由系统完成。越权、异常或资源不足时自动拒绝、等待或结束，界面只报告状态，不要求人守着确认。

浏览与回答是两个独立开关。默认允许已授权范围内浏览，不自动回答入站请求；人可开启自动回答。收到 act 或文件 Offer 时主动通知 Agent；没有接收权限时进入“请求用户授权”。上传与下载也分别配置为“授权内自动”或“每次询问”。询问按文件内容、接收者及授权版本绑定，传输内容或对象变化需重新确认；超时、拒绝或撤权均不传输。询问仅在本地授权设置选择该模式时出现。

目录授权的语义必须明确：符合规则的内容会进入获准披露的快照。应用不能保证识别用户放入目录的所有秘密。

## 4. 身份、联系人与可见性

稳定身份与传输设备身份分离：

- 本地保护的 secp256k1 身份根密钥控制 Agent。`AgentId` 由初始根公钥确定，并在公共链登记最小状态。链状态只证明密钥控制和有序更新，不证明真人、一人一 Agent、设备安全或 Agent 善意。
- 每台设备生成独立 libp2p Ed25519 密钥及 `PeerId`。身份根密钥签发有序号、签发时间和失效时间的设备证书，绑定 AgentId 与 PeerId。传输握手认证设备密钥，应用握手再验证证书及最终化链状态；消息自报的 PeerId/AgentId 不构成认证。
- 联系人固定 AgentId，而不是某个网络地址或设备。每台设备必须持有该 AgentId 根密钥签发的有效证书；移除设备后拒绝它发起的新会话。
- 设备目录和公开概念标签由根密钥签名后以有期限的 DHT 记录发布。DHT 只提供候选，不是身份登记机关，也不保证完整、唯一或及时。

1.0 必须使用公共区块链身份登记，但不运行自有链或单一身份服务。链上仅保存当前控制地址、设备状态承诺、严格递增序号和撤销状态；不保存资料、IP、联系人、查询、群组、文件标识、信任、贡献或授权。链交易 gas 由可替换的志愿赞助者或选择自付的用户承担，ASL 不收费、不发币。赞助者可限流、拒绝或退出。

持久数字短码由 AgentId 派生并通过 DHT 查询，可碰撞、被隐藏或污染；查询返回一个或多个待核验候选。客户端验证新鲜的最终化区块头、注册合约代码和状态证明，再验证设备证书与当前认证连接 PeerId。首次联系人仍通过完整指纹/二维码或一次性 PAKE 核验后才本地钉住。身份解析使用版本化接口，以便未来更换公共链适配器，不改变本地 AgentId、联系人和迁移数据格式。

“匿名”在文案中使用“隐藏公开资料/假名身份”；不承诺网络匿名。直连会向通信对端暴露网络地址；DHT 查询、在线时间、公开标签和中继元数据也可能被关联。仅中继模式仍不隐藏流量关系或中继运营者可见的元数据。

公开资料只含版本化概念 ID 和明确授权的头像内容引用，不含名字、描述、粗略地区或任意标签文本。头像仅为经过重新编码的 PNG/WebP，尺寸不超过 128×128，原始字节不超过 64 KiB，头像本体按授权拉取，不塞进 DHT。禁用远端 SVG、动画、外链与 HTML。本地昵称可供 GUI 显示，但不在线发布。

GUI 中的联系人操作是对身份授予或撤销 contacts 范围访问权，属于授权。Agent 自己生成的“优先问这个节点”只写偏好表，不进入联系人授权表。

身份迁移包由用户显式导出并使用成熟加密格式保护，携带身份根密钥、联系人钉住表、信任偏好及用户选择的 ASL 资料。目标设备生成新的设备密钥，由身份根密钥签发设备证书；按链上状态承诺更新设备集合，群组通过 MLS 新设备成员流程加入，不复制会导致分叉的本地 ratchet 状态。原设备应在迁移时停止或撤销，避免同一设备证书并发活动。目录路径、OS 凭据和文件授权不迁移，必须在新设备重新授权。

根密钥丢失或泄露时，没有中心机构可以找回。能控制旧根密钥时可提交链上轮换/吊销；根密钥遗失时不能凭空恢复原身份，需另建身份并由联系人重新核验。重置和导入均为明确授权配置行为，不是 Agent 的后台自主操作。

## 5. 搜索的真实语义

本地检索覆盖授权资源内容和本地语义索引。语义索引可以用本地全文检索或本机模型构建；其查询词不得未经映射直接发送到网络。

DHT 的概念 ID 查询只发现“声称提供相关公开资源的节点”。真实结果经直连和权限验证后产生。默认最多查 3 个公开概念键、直询 16 个候选，单轮 10 秒；联系人优先。

持久数字短码查询使用单独的 DHT 键，返回候选列表而非唯一身份。短码可碰撞，查询结果可能被隐藏或污染；只有链状态证明、设备证书和本机核验完成后才能标记为已验证联系人。一次性邀请码用于 PAKE 配对，有效期短、尝试次数有限且成功后失效；二维码/签名邀请链接是长数字码以外的优先方式。

不会声称返回全网所有内容或展示全网在线状态。没有命中返回 `no_match`，节点离线返回 `offline`，不把失联的旧记录包装成可下载资源。

确定性 query/answer 继续只包含版本化概念 ID、类型化实体/关系、约束、期望结果形态、证据引用和预算，不含任意文本；无法映射到共享词表的内容不能伪装成字符串、文件名或任意二进制字段。需要自由表达时使用 ASL/1.3 `act`，自然语言只写入 MLS 解密后的 `nl-body`。人类可在 GUI 用本地化文字观察结构化活动。允许只联系指定节点、不走公共 DHT 的任务模式。

## 6. 文件与经验

文件以独立的不透明字节载荷传输，不是 Agent 控制或语义消息。`act` 附件只携带 `blob-ref`，实际字节继续走 `offer -> fetch -> chunk -> hash`；文件名、路径和文件字节都不进入 `nl-body`。载荷内的文本不会自动解析为会话、指令或模型上下文。文件不执行脚本、宏或程序。索引支持获授权的 Markdown、TXT、Rust/其他源码、JSON，以及在受限 helper 中提取文本的 PDF。扩展名用于本地授权过滤，不代表内容可信。将文件交给模型处理还需本机单独授权。

固定 1 MiB 块，完整支持恢复和多来源；单文件硬上限 64 GiB。超限明确拒绝，不静默截断。文件名由本地程序生成，远端标题只作为可清洗的显示字段。

经验采用“结论、适用条件、证据引用、来源、验证状态”的结构。涉及远端输入时默认私有；人可以规则级授权引用或发布特定来源，但不逐条审批。公共经验也带“未经独立验证”状态，不能成为系统指令。

## 7. 信任与贡献

信任记录完整性、承诺兑现、可用性和证据质量；模型对“有用”的评价只是弱信号。贡献仅计入本机真实任务实际使用的有效帮助，不按对方自报、上传字节、在线时长计分。

每个 `task_id + content_id + help_kind` 最多记一次。内容相同、请求重放或重复块不能反复记分。不同身份的刷号无法被完全识别，统一资源上限与新人探索总额度限制其收益。

繁忙时采用本地公平队列并给予可靠贡献者软优先，空闲时尽量服务所有获准请求。信任/贡献永远不能改变目录、联系人、外部模型和写入权限。

## 8. 明确不属于产品的承诺

不做以中心服务器承载明文的离线邮箱、匿名网络、远端代码执行、中心化身份服务、全网积分、保证搜索完整性、保证打洞成功、保证其他节点删除副本或链上真人身份认证。加密邮箱只存密文；托管节点、gossip 邻居和中继仍可见有限的连接、大小和时间元数据。

区块链只登记密钥控制的身份状态，不证明真人、一人一 Agent、Agent 语义真实性、设备安全或抗刷号。DHT 短码解析是尽力而为的发现线索，不等同于全网可达或可用。链上 gas 由志愿赞助者或用户承担；没有可用赞助者时新身份可保持待锚定，只能按本机配置进行局域网或本地活动。离线消息进入有界密文邮箱；容量不足或 TTL 到期时必须明确报告，不能承诺无限保留。完整性 hash 证明字节一致，不证明事实真实，也不能阻止对端文本中的提示注入。

## 9. 群聊

私聊是两个成员的 MLS 组，与群聊共用 act、预算、密文邮箱、历史、附件和通知路径。群是由成员共同使用的端到端加密房间，不设固定 64 人业务上限；小群按已认证成员 direct fan-out，中大群用 gossipsub 传播 MLS 密文，万人级必须使用分层拓扑。容量由本机 CPU、内存、磁盘、带宽、MLS 操作延迟、邮箱分片和 gossip 收敛时间实测决定。群邀请与成员变更必须命中用户授权策略，MLS Commit 才改变成员资格；gossip 只传播密文，不授予权限。

群名、成员列表和历史记录不发布到 DHT。离线消息使用按固定大小桶填充、可分片、带 TTL 和 pseudonymous topic 轮换的加密邮箱；托管节点只看到密文摘要、槽位、大小和期限，看不到 `nl-body`、群名、文件名或明文主题。MLS 凭证绑定 AgentId 与当前设备证书；迁移到新设备后作为新叶子加入，不复制旧设备的 MLS ratchet 状态。群成员身份只代表加入该房间，不自动获得联系人权限、共享文件权限或模型处理权限。

每个群有一个由 MLS room creator 绑定的群主。群主可指定管理员、设置成员默认文字/文件/邀请权限并禁言具体设备；策略通过 MLS 加密的 `group-policy` 传播，revision 单调递增。管理员和成员不能自称群主或修改策略。群角色只约束该房间内的 act、查询和 Offer，不能替代用户目录授权、收件目录、设备证书或传输审批。GUI 的群成员区显示角色和权限，MCP 群管理工具使用同一状态。

若本地资源授权明确选择某群作为披露范围，访问仅对当前群成员有效；成员版本变化后重新判定，移除成员不得取得后续群范围资源。群文件使用 `blob-ref` 和既有授权传输，成员变化立即影响新请求。已被成员接收或保存的数据无法远程召回。

群 act 只有在本机“回答”已启用、预算仍有效且资源对该 audience 授权时才可生成答复。每次模型上下文只放当前会话成员、发送者和本机策略共同允许的资料，避免把只授权给另一会话的数据写进回复。群回复可以继续触发回复，但 `act-id`、`reply-to`、`causal-root`、`hop`、epoch、去重和可续期预算共同阻止无界循环。支持浏览而不回答。
