ASL UI asset record
===================

Pixel product icon and agent mascot
-----------------------------------
- Source: scripts/generate-art.py; see docs/assets/ART-SOURCE.md
- Creator: ASL project contributors; original programmatically drawn pixel designs
- Method: offline Pillow render for the product icon, mascot states, preset avatars, and state glyphs
- External image URLs and third-party or copied art: none
- License: MIT, under the repository LICENSE

Fonts
-----
- UI base fonts: eframe/egui default fonts, supplied by the locked Rust dependency
- Windows CJK fallback: installed Microsoft YaHei (msyh.ttc), loaded from the Windows Fonts directory when present
- Font files are not copied into or redistributed by this repository; their owner-set license remains applicable
