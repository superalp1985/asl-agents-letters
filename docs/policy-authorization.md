# T07 纯授权判定

状态：2026-11-18 纯授权核心已实现，36 项授权测试及工作区 144 项测试通过。独立只读工程复核无阻断发现；这不是完整授权链路或产品验收。

## 模块边界

`asl-policy` 的类型、对象范围、来源展开和判定服务分开实现。判定使用可信 core 提供的本机事实，不访问网络、文件、模型或数据库。信任分数、贡献、昵称、头像和自动偏好不属于判定输入。

`AccessRequest` 保留冻结的 grant、resource、principal 和 operation 四个字段。已认证设备及群上下文由本机创建的服务视图携带：

- 本机 `PolicyEngine` 处理已经登记的本地任务，以及独立获准模型的输入。
- `for_peer` 将请求绑定到传输认证和身份验证已经完成的设备。
- `for_group` 另外绑定当前有效 MLS 群和成员版本。

这些事实必须来自身份与群验证模块；构造本地事实不等于完成密码学验证。对端自报 AgentId、PeerId 或“已验证”布尔值不能进入这些入口。

## 授权规则

读取要求资源有效、快照 ready、grant 有效且版本匹配，类型、大小、保留期和操作均符合规则。public 仍要求有效链身份及设备证书。contacts 按稳定 AgentId 匹配；peers 只匹配明确授权的 AgentId；group 要求当前设备属于指定的有效群。

模型输入逐来源求交：全部来源必须允许同一个已获准 provider。`never` 拒绝所有 provider；`local_only` 还要求明确列入本地 provider 名单。为某个对端生成回答时，使用该对端的服务视图，同时检查对端是否有权知道这些来源；不能把本机模型可读等同于可以发给陌生对端。

派生资料最多 8 个直接来源，最多 32 个展开后的叶来源引用，最大深度 4。展开检查循环、来源缺失及每个中间资源的有效性。对外披露需全部来源允许同一接收者，并允许派生披露；公开公告要求全部来源为 public。无法判定的来源图不能对外披露或交给模型。

私有派生结果可以在授权范围内本机浏览；对外披露与模型处理分别判定。远端来源的派生再利用需要明确允许，不能因保存到本地目录就自动公开。

## 短期许可

`Permit` 只能由服务构造，没有接受远端输入的反序列化入口。它绑定本次服务实例、设备/群上下文、资源及内容 ID、操作、grant 及来源版本和期限。另一服务实例、另一设备、另一群版本或重启后的旧许可都不能继续使用。

每次重新验证都会重算当前授权。全局 revision 变化触发重判；无关变化不会单独使合法许可失效。联系人移除、设备失效、源资源停用、内容更换、任一来源版本改变或许可到期都会阻止继续使用。期限还受来源保留期、链身份和设备证书期限限制。

不存在与未获准的资源统一返回 `NotFound`，避免借错误差异枚举本机资料。

## 集成限制

这里的 `revoke` 是有版本检查的内存状态转换，不能宣传成已经提交的 SQLite 撤销事务。后续 core 必须先提交 durable epoch/revision、停用引用和审计，再取消相关队列、读取、模型调用和待发数据。

`WriteDerived` 仅允许使用来源生成经验。目标写目录授权、目录句柄、磁盘预留和写入仍是额外条件，不能持有该许可就自行打开任意文件。

纯判定不替代 Windows 文件句柄边界、沙箱、网络认证、MLS、传输确认、lease 或撤销栅栏。浏览/回答开关及传输确认的完整状态机属于后续 Agent/core 集成。
