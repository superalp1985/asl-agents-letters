# ASL 1.0 真人/真实环境验收清单

状态：代码和本机自动化验收已完成；以下项目不能由本机单元测试或回环测试替代。全部完成前，构建产物只标记为测试包。

## 1. 两台 Windows 11 x64 真机

- 使用干净用户目录分别安装、首次启动并选择中文或英文。
- 用完整 AgentId、二维码、临时邀请和 6/12 位 PAKE 分别完成联系人配对。
- 验证错误 PAKE 短码一次后失效；关闭并重启后旧短码不能再次尝试。
- 双方互发结构化 `Act`、查询、回答、表达和附件引用；确认没有被迫使用自由文本。
- 双向传文件，覆盖每次询问、自动授权、拒绝、断线、重启续传和整文件哈希。
- 验证关闭窗口隐藏到托盘、提示音开关、托盘菜单和真正退出。
- 在 100%、125%、150%、200% DPI，以及中文/英文和长名称下截图并检查文字不重叠。

## 2. 公网 NAT、relay 与 AppContainer

- 两台机器位于不同 NAT 后，使用独立 bootstrap 和 relay 配置完成首次入网。
- 记录 AutoNAT 结果、DCUtR 直连升级、relay 降级、断网重连和 route 失败原因。
- 在管理员 PowerShell 中执行 AppContainer 回环测试；核对临时防火墙豁免被清理。
- 至少运行 72 小时，覆盖重启、离线 owner、目标设备重连、跨 shard Fetch 和邮箱补收。

## 3. 多设备同一 Agent

- 同一根身份在两台设备启用加密策略同步，修改联系人策略并在 60 秒窗口内观察另一台设备收敛。
- 制造相同 revision 的并发策略，确认撤销优先和记录哈希决胜结果一致。
- 撤销一条策略并确认旧 revision 不能恢复；授权同步开关必须在每台设备本地重新批准。
- 执行身份迁移，确认联系人重绑定、旧设备撤销、新 PeerId 重新入群和联系人授权边界。

## 4. 群组与权限

- 三台以上真机完成建群、邀请、拒绝、重入、管理员、禁言、逐文件 `read/send/fetch` 和邀请权限。
- 群主转移后，由新 owner 移除成员；验证原 creator 不再保留移除特权。
- 由 `manage-members` 管理员发起移除和代管，owner 复核；失败请求保持待审且不能越权。
- 跨 shard 文件请求验证 `FetchGrant/FetchPending` 只回到真实请求方，不向无关 shard 广播。

## 5. 容量矩阵

- 覆盖 512、2,000、10,000 个唯一 Agent 的分层群规划与跨机投递。
- 记录 CPU、RSS、磁盘、消息延迟、转发积压、outbox 恢复和 72 小时收敛。
- 单 shard 512、逻辑群 10,000、最多 20 个 shard 是当前验收边界；不得把更大规模写成已验证。

## 6. 真实区块链

- 在目标网络部署身份注册表，配置真实 RPC、可信 checkpoint、合约地址和代码哈希。
- 验证 sponsor、自付和 fallback 三条路径，以及注册、更新、最终性等待、撤销和迁移。
- 保存交易哈希、最终区块、证明输入摘要和撤销结果；不得在仓库写死地址、RPC 或私钥。

## 7. 发布与安全

- 用生产签名密钥构建并验证 Windows/Linux 安装、升级、回滚、更新签名和 SBOM。
- 在干净机器上核对安装包 SHA-256、签名、版本、数据目录和卸载行为。
- 完成独立安全审计和提示注入、跨 audience 外泄、分身资源压测；自动化测试不能替代该审计。

## 验收证据

- 每项记录日期、设备/OS、版本、操作步骤、结果、日志路径和截图。
- 网络项记录 PeerId、AgentId 摘要、NAT/relay 结果，不提交私钥和联系人明文。
- 链项记录公开交易哈希和最终区块。
- 发布项记录签名指纹、包哈希、SBOM 和安装/升级/回滚结果。
